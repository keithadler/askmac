# Privacy

Ask for Mac reads the files Spotlight finds for your question, while it answers, and keeps none of them. It uses the Mac's own Spotlight index and, on macOS 26 with Apple Intelligence, Apple's on-device language model; neither leaves the Mac, and Ask for Mac never uses Apple's Private Cloud Compute or any other server.

The only things it stores are its settings and, if you leave it on, your recent questions, in its own preferences. Turn that off or clear it in Settings.

One optional network request: once a day it asks GitHub for the version number of the latest release. Nothing about you or your Mac is sent with it. No analytics, no crash reporting, no account.
