Getting started

Press ⌥ Space in any app: a panel floats over your work, like Spotlight. Type a question the way you would ask a person who had read everything in your Documents, Desktop, Downloads, iCloud Drive and Mail. Press Return, or press ⌥ Space from any app to bring the window forward first. The sources appear as soon as they are ranked and the answer streams in above them; Open opens one, the folder button shows it in Finder, the arrow shows the passage it was taken from.

Nothing needs setting up. Ask for Mac uses the index your Mac already keeps (Spotlight) to find candidate files, then reads those files itself while it answers, and keeps nothing afterwards.

How it answers

  1. Find. Spotlight is asked for files whose text or name contains your words, within the date window if you named one.
  2. Read. Those files are read on the Mac: PDF, Word, Excel, PowerPoint, RTF, HTML, text, Markdown, CSV and Mail messages, plus screenshots and Apple Notes when asked for. The window says what it is doing as it goes.
  3. Rank. Each file is split into passages. Passages score on the words they contain and, using the Mac's own language model for word meaning, how close they are to the question. The best few win; no single file may take more than three places.
  4. Answer. On macOS 26 with Apple Intelligence on, Apple's on-device model writes two or three sentences from those passages, each fact followed by a citation like [1], and says The files I found do not answer that when they do not. Otherwise the answer is the best-matching sentence quoted from the top file.

Either way, the sources are listed. An answer you cannot check is not an answer.

Keys

⌥ Space opens the quick panel from any app, Escape closes it. Return asks. ⌘. stops. ⌘1 to ⌘9 open the numbered source. ⇧⌘C copies the answer with its sources. The eye button on a source is Quick Look. PDF sources say which page the passage is on.

Asking well

  • Use the words that would be in the file. "lease deposit" beats "how much did I pay the landlord up front", because the file says deposit.
  • Dates help. "last week", "yesterday", "in March", "from Tuesday", "2025", "3 weeks ago" all narrow the search to files changed then.
  • Name the kind when you know it: "the lease PDF", "email from Sam", "spreadsheet with the budget".
  • Follow-ups work. After "lease deposit", ask "and when is rent due" or "what about the gutters"; the previous question's words and dates carry over. A short question that finds nothing on its own is retried the same way.
  • Fewer words when nothing is found. Every word must appear somewhere; drop the ones you are least sure of.

What it searches

Documents, Desktop, Downloads and iCloud Drive by default; add or remove folders in Settings, and skip folders inside them that you never want searched (a folder of code repositories, say). Mail is included when Ask for Mac has Full Disk Access, which macOS requires for reading another app's mail store; without it, files still work.

Screenshots and photos are read with the Mac's own text recognition, but only when the question asks for a picture ("the screenshot of the wifi password", "photo of the receipt"), since reading every image for every question would be slow. Images matching the words in their name come first; failing that, the newest screenshots.

Apple Notes are read through the Notes app when a question mentions notes. macOS asks once whether Ask for Mac may control Notes; say yes and notes join the sources, with an Open in Notes button. Numbers, Pages and Keynote documents are read through the preview image Apple stores inside each one, so the first page only, and only when the document was saved with a preview (the default).

One folder. Right-click a folder in Finder and choose Services › Ask for Mac About This, or drop a folder on the window, and the next questions look only there; the folder shows as a chip next to the question, with an × to search everywhere again. On the command line, --in <folder>.

Apple Intelligence

Written answers use Apple's on-device model, which exists on macOS 26 on Apple silicon with Apple Intelligence turned on in System Settings. The status line at the bottom of the window says which mode you are in. The model runs entirely on the Mac; Ask for Mac never uses Private Cloud Compute or any other server. Turn it off in Settings to always get quoted sentences instead.

Command line

ln -s "/Applications/Ask for Mac.app/Contents/MacOS/AskMac" /usr/local/bin/askmac
askmac "lease deposit last week"
askmac "dentist invoice crown" --json
askmac "tax return 2025 total" --quote     # skip the on-device model
askmac status
askmac folders add ~/Projects

Exit code 0 when answered, 1 when nothing was found.

Privacy

Nothing leaves the Mac: not the question, not the files, not the answer. There is no index of your files beyond the one macOS already keeps. Recent questions are remembered in the app's own settings and can be turned off or cleared in Settings. The daily update check asks GitHub for a version number and sends nothing about you.

Troubleshooting

It finds nothing, but the file exists

Spotlight may not have indexed that folder yet, or indexing is off for it (System Settings › Spotlight › Search Privacy). When indexing is off for a whole volume, the app says so under the question. Ask for Mac falls back to reading the folder directly when Spotlight returns nothing, which is slower but works.

The answer quotes a sentence instead of writing one

That is the mode without Apple Intelligence. The status line at the bottom says why: older macOS, an Intel Mac, Apple Intelligence off, or its model still downloading.

Mail is not included

Give Ask for Mac Full Disk Access in System Settings › Privacy & Security, then ask again.
